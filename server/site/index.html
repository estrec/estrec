estrec

The estimation record: what was estimated, what came out, and how and where it ran, as a small JSON file that any software can write and read.

0.1 draft for comment. The format may still change. Issues and comments are welcome on GitHub.

Start here

  • Record viewerOpen records and collections, build a regression table, export it or publish it. Files stay in your browser.
  • SpecificationThe core, profiles, collections and disclosure levels.
  • SchemasJSON Schema 2020-12, served at their $ids under /schema/.
  • SourceThe reference tools (MIT); the spec and schemas are CC0.

Write a record

The reference validator, writer and redactor:

pip install "estrec[jsonschema] @ git+https://github.com/estrec/estrec"
estrec validate model.estrec.json

Without git (the command above needs it on your PATH):

pip install "estrec[jsonschema] @ https://github.com/estrec/estrec/archive/refs/heads/main.zip"

From fixest fits (feols, feglm, fepois):

remotes::install_github("estrec/estrec", subdir = "r")
estrec::write_estimation(fit, "fit.estrec.json")

Stata 16 or later. Run estrec write right after an estimation command (regress, reghdfe, ivreghdfe, logit and others):

net install estrec, from("https://raw.githubusercontent.com/estrec/estrec/main/stata") replace
regress price mpg weight, vce(cluster rep78)
estrec write using "price.estrec.json", replace

SPSS, SAS, Julia and other tools don't have a writer yet. A record is plain JSON, so any tool can write one by following the specification; the converters are short worked examples, and the Python validator checks the result. If you'd like a writer for your tool, say so on GitHub.

Published tables

A table published from the viewer gets an unlisted link at estrec.org/t/…. Identifying details (user, host, paths) are removed before it is stored. It is kept for a year after its last view, and you can delete it any time with the link you get when you publish. Licence: CC0 by default, or CC BY or CC BY-SA.
